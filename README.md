# CodeAlpha EDA – Superstore Sales Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore Sales dataset using Python.

## Objectives
- Understand the dataset structure and data types.
- Clean missing values and duplicate records.
- Analyze sales by category, sub-category, region, and customer segment.
- Explore monthly sales trends.
- Analyze shipping time by shipping mode.
- Identify patterns and useful business insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `CodeAlpha_EDA_Superstore_Sales.ipynb` – EDA code and visualizations.
- `train.csv` – Dataset used for analysis, if sharing is permitted.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Ensure the dataset path is correct.
5. Run the notebook cells in order.
